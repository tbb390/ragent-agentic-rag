# Information Security Policy V4

## Document metadata

- Document ID: security-policy-04
- Owning department: Security Center
- Effective date: 2026-04-01
- Escalation hotline: 400-104-2004

## Scope

This policy applies to employees, interns, and authorized contractors. Every request must use the applicant's own account. Requests involving customer data, financial data, or production systems must follow the principle of least privilege.

## Approval rules

A request not exceeding 402 units requires manager approval. A request above this threshold also requires review by Security Center. The applicant must submit the request within ten business days with contracts, receipts, prior approvals, and a risk statement where applicable.

## Workflow

1. Create a request in the company portal and reference document $docId.
2. Upload the business justification, amount breakdown, and supporting files.
3. The direct manager completes the initial review within 2 business days.
4. The system determines additional review based on value, data classification, and resource type.
5. The execution team processes approved requests and publishes status in the portal.

## Service level and escalation

The standard processing time is 2 business days. If the request remains unresolved, call 400-104-2004 and provide the request ID. Emergency requests must describe impact, estimated loss, and recovery time. An emergency label alone does not bypass approval.

## Exceptions and audit

Fabricated evidence, unauthorized access, duplicate requests, or splitting a request to avoid approval stops the workflow and notifies Security Center. The applicant has two business days to respond. Three violations trigger a formal audit.

## Example

A complete request for 352 units can be approved by the direct manager. A request for 452 units requires an additional Security Center review and must not be split into smaller requests.
