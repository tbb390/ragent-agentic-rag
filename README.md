# Ragent AI - Agentic RAG Platform（二次开发版）

## 项目介绍

本项目基于开源项目 Ragent 进行二次开发。

原项目地址：
https://github.com/nageoffer/ragent

本人在本地完成项目源码学习、架构分析以及功能扩展，针对企业级 Agentic RAG 平台进行了多项调整与优化，包括知识库处理流程优化、Embedding Pipeline 改进、异步任务稳定性提升、性能测试体系完善以及项目架构文档整理等。

---

## 二次开发内容

### 1. RAG 知识库链路优化

针对知识库从文档解析、文本切分、Embedding 到向量存储的完整流程进行了分析和调整：

- 梳理 RAG 数据处理链路
- 优化知识文档处理流程
- 排查并修复 RocketMQ 异步消费过程中的 Chunk 处理异常
- 提升知识库文档处理稳定性

---

### 2. Embedding Pipeline 优化

针对批量文档向量化过程进行了多项调整：

- 增加批量 Embedding 调度能力
- 引入受限并发处理机制
- 优化任务异常处理流程
- 保证并发执行后的结果顺序一致

性能测试结果：

- 平均处理耗时：
  510ms → 136ms
- 吞吐能力提升约 3.75 倍

---

### 3. Agent / MCP 模块分析与完善

对项目 Agent 执行流程进行了深入分析：

- 梳理 Agent 请求执行链路
- 分析 RAG 检索流程
- 研究 MCP Tool 调用机制
- 整理项目模块关系和运行流程

---

### 4. 测试与工程化完善

新增：

- Embedding 性能测试代码
- RAG 数据集生成脚本
- 文档处理性能验证流程
- 项目架构分析文档
